# HELIX 1.0: A Year In The Making

After a year of experiments, this is the first public HELIX engine release.

The idea that survived the experiments is small: keep the original evidence, stop replaying information an agent no longer needs, and do not ask a model to make a mechanical decision it already made.

This release brings ordered goals, verified receipts, exact recovery, indexed evidence, deterministic memory, a read-only Claude-Mem bridge, RTK archive filtering and the local Electron app into one package. The app now shows observed model phases, lights its reasoning panel only when reasoning is actually observed, browses memory and offers local diagnostics. Light, dark and system themes remain. The harness double-strand mark returns here.

The results are mixed, and that belongs in the release notes. On the same50 historical NEW50 comparison, V3 used 77.73% fewer known provider tokens, but generated 37.14% more output and solved 34/50 versus vanilla's 38/50. Failures, retries and rejected finalization work are included. All official grades completed; the solver was then terminated after a completion-broker defect rather than claiming a clean exit. There is one ordinary modified request with unknown usage. No billed-cost or quality-equivalence claim is made.

Private memories, credentials, raw sessions and hidden patches stay local. The published evidence is reconstructed from numeric and public-issue allowlists. New memory/RTK/UI features have deterministic integration tests, not a new savings trial.

This is a useful starting point, not the end of the output-efficiency work. Thank you for looking carefully, trying it, and reporting what actually happens.

Source installation is the supported distribution in this first release. Unsigned macOS packaging is separately tested when attached; Windows/Linux binaries are not claimed without native tests. See the README for installation, module details and known limitations.
